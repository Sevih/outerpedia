# Dépendances des scripts python du projet — chacun lit un format binaire
# spécialisé vers un JSON committé (cf. datagen/README § « Exception assumée :
# l'outillage Python ») :
#   - assets/extract-face-layout.py   → face-icon-layout.json      (cadrage des FI_)
#   - assets/extract-sprite-rect.py   → sprite-rect.json           (taille logique des
#                                       sprites rognés par le packer d'atlas)
#   - assets/extract-portrait-fx.py   → portrait-fx.json           (effet animé du
#                                       portrait : table + textures PNG du pool)
#   - assets/extract-font-metrics.py  → portrait-font-metrics.json (chasses des
#                                       polices du portrait)
#
#   python -m pip install -r datagen/requirements.txt
#
